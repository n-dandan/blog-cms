## （1）制作アプリのタイトル
ブログ用CMS

## （2）制作アプリの説明（40文字程度）
Webサイトに公開するためのCMSを自作してみました。

## （3）工夫した点・こだわった点
- **編集体験にこだわった**：ヒーロー画像・本文画像を**ドラッグ&ドロップで入稿**でき、本文はサーバー側と同じ規則で**ライブプレビュー**しながら編集できる。タグは色が付くボタン型UIで選択、公開状態の切り替えや未保存のままキャンセルした場合は確認ポップアップを出すなど、誤操作を防ぐ工夫を入れた。
- ヒーロー画像の表示比率を16:9に統一して、同じ見た目になるようにした。
- **セキュリティ対策を一通り実装した**：全SQLをPDOのプリペアドステートメントで実行しSQLインジェクションを防止。パスワードは `password_hash` / `password_verify` でハッシュ化、フォームにはCSRFトークンを埋め込み、出力は `htmlspecialchars` でエスケープしてXSSを防止。
- **画像アップロードを安全に**：拡張子やContent-Typeは信用せず、実バイナリからMIMEを判定。サイズ上限（5MB）や保存名のランダム化、アップロードディレクトリでのPHP実行禁止（`.htaccess`）も行った。
- **将来の転用を意識した設計**：記事とお知らせを `type` で区別する汎用的な「投稿」テーブルにし、読み取り専用のJSON APIを用意。別アプリ（React）から `fetch` でお知らせを取得できるヘッドレスCMS的な構成にした。
- **公開／非公開の切り分け**：`config.php` やロジック（`src/`）・テンプレート（`views/`）は `.htaccess` で直接アクセスを禁止し、ブラウザに配信するのは `public/` の中だけになるようにした。

## （4）難しかった点・次回トライしたいこと（または機能）
**難しかった点**
- 本当は編集画面の中で画像を表示させたかったが、`[image:ID]`で入れることしかできなかった。新規投稿では投稿IDがまだ無いため、本文画像を即時アップロードして `[image:ID]` を挿入する仕組みと相性が悪かった。「新規作成」で空の下書きを先に作ってから編集画面へ遷移させることで、常にIDがある状態にして解決した。
- 本文の `[image:ID]` プレースホルダーを、サーバー側の表示とJS側のライブプレビューで**同じ見た目になるように**揃えるのに苦労した。

**次回トライしたいこと**
- このCMSを実際のコンテンツに実装すること。
- OGP画像の表示も投稿編集画面に含める。


## （5）所感
いままではCMSを使う側として機能が少ないなど思っていたが、実装してみると結構大変だった。
AIを活用して制作しているが、各画面での画像の比率がバラバラで見たこともない比率で出された時は信じられなかった。
世の中のブログ系のコンテンツの画像比率の統一感の無さというのは、技術偏重なせいかもしれないと感じた。

## （6）使用技術

- **バックエンド**：PHP 8.2（フレームワーク不使用の素のPHP）
- **データベース**：MariaDB 10.4（MySQL互換） / PDO（プリペアドステートメント）
- **フロントエンド**：HTML / CSS / 素のJavaScript（ライブラリ不使用）
- **Webサーバー**：Apache（`.htaccess` によるアクセス制御・URLルーティング）
- **開発環境**：XAMPP、VS Code
- **認証・セキュリティ**：セッション認証、`password_hash`、CSRFトークン、`htmlspecialchars`
- **API**：読み取り専用のJSON API（GET限定）

## （7）構成

```
blog-cms/
├── config.php                 # DB接続情報（.htaccessで直接アクセス禁止）
├── public/                    # 公開ディレクトリ（ブラウザからアクセスするのはここだけ）
│   ├── index.php              # 投稿一覧（検索・ページネーション）
│   ├── show.php               # 投稿詳細（コメント管理）
│   ├── create.php             # 新規作成（空の下書きを作成して編集画面へ）
│   ├── edit.php               # 投稿編集（D&D入稿・ライブプレビュー）
│   ├── delete.php             # 削除確認・実行
│   ├── login.php / logout.php # ログイン / ログアウト
│   ├── tags.php               # タグ管理（作成・削除）
│   ├── toggle_status.php      # 公開状態の切り替え
│   ├── upload_body_image.php  # 本文用画像のAJAXアップロード
│   ├── delete_hero_image.php  # ヒーロー画像の即時削除
│   ├── css/style.css
│   ├── js/editor.js           # ドロップ入稿 + 本文ライブプレビュー
│   ├── api/posts.php          # 公開JSON API（読み取り専用）
│   └── uploads/posts/{id}/    # 画像保存先（.htaccessでPHP実行禁止）
├── src/                       # サーバー内部のロジック（非公開）
│   ├── db.php                 # PDO接続
│   ├── auth.php               # 認証・セッション
│   ├── csrf.php               # CSRFトークン
│   ├── helpers.php            # 共通ヘルパー
│   ├── upload.php             # 画像アップロード（検証・保存・削除）
│   ├── Post.php               # 投稿のCRUD
│   ├── Tag.php                # タグ（多対多）
│   ├── PostImage.php          # 本文中画像（[image:ID] 置換）
│   └── Comment.php            # コメント
├── views/                     # 画面テンプレート（非公開）
│   ├── header.php / footer.php
│   └── post_form.php          # 投稿編集フォーム
└── sql/
    ├── schema.sql             # テーブル定義 + 初期データ
    └── migrate_phase4.sql     # 追加マイグレーション
```
